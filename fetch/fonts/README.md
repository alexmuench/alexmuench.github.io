# Wordmark font: Dogways

The welcome-screen "Fetch" wordmark is wired to use **Dogways**
(https://www.dafont.com/dogways.font) when a font file exists here:

1. Download the font from DaFont and check the license note in the zip —
   DaFont display fonts are typically **free for personal use only**.
2. Drop the file in this folder as `dogways.ttf` (or better, convert to
   `dogways.woff2`, e.g. https://cloudconvert.com/ttf-to-woff2).
3. Done — no code changes needed. Without the file, the wordmark falls
   back to SF Rounded.

Tip: you can also upload the .ttf to Claude in the session and it will be
subset to the five letters and converted for you.
